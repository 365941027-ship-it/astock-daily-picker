# A股每日短线选股小程序

一个基于历史复盘口径的每日选股小工具：自动拉取全市场行情，按既定规则过滤、评分、归类，输出 Markdown / Word 日报。纯 Python 标准库即可运行（Word 输出需 `python-docx`）。

## 网页版（推荐）

除了命令行，还自带一个网页版界面，可以在浏览器（含手机）里选参数、看运行日志、浏览选股结果，并点开个股看 K 线图。

```bash
python webapp.py                 # 启动本地服务，默认 http://127.0.0.1:8234
python webapp.py --port 9000     # 自定义端口
```

然后在浏览器打开 http://127.0.0.1:8234 即可。页面支持：

- 选日期、优先观察数量、代理地址、强制刷新、盘中预览开关；
- 实时运行日志与进度；
- 市场环境（涨跌家数、涨停数、指数）与三类结果表格；
- 点击股票名称弹出 K 线详情（MA5/10/20、MACD、KDJ、涨幅）；
- 预判核对：复盘前一交易日观察 vs 当日实际，自动标注“兑现 / 失效”并给出修正建议；
- 一键下载 Markdown / Word 日报；
- 参数自动保存在浏览器本地，下次打开沿用。

### 历史回放

页面上的「历史回放」可以把之前每个交易日都用同一套口径重新跑一遍选股：

1. 选择起始/结束日期（默认 2026-07-01 ~ 最近交易日，可改成任意区间）；
2. 点「开始历史回放」，完成后会出现日期列表；
3. 点击任意日期即可查看当天的候选（优先观察 / 强势不宜追高 / 剔除观察）。

历史回放完全基于本地缓存离线计算，秒级完成，结果按天保存在 `daily_picker/cache/replay/` 下，重启服务也不会丢。

> 口径说明：历史回放基于当前满足流动性+收红口径的股票池缓存逐日重算。日K缓存若来自新浪兜底源（不含成交额/换手率），涨幅会按收盘价自行重算、成交额按「成交量×收盘价」估算、换手率门槛暂不参与过滤，因此历史日期的候选与当时实时筛选可能存在差异，仅供回顾参考。

### 预判核对

「预判核对」用来复盘“前一交易日观察 vs 当日实际走向”，并据此修正后续观察：

1. 选一个“核对日”（默认最近一个有次日数据的交易日）；
2. 表格列出该核对日前一交易日选出的候选：观察日收盘、支撑位（MA5/MA10 较低者）、次日收盘/涨跌/最低价；
3. 自动判定：
   - **兑现**：回踩支撑不破并拉起，可继续跟踪；
   - **失效**：跌破支撑或次日大跌，从观察池剔除；
   - **未回踩走强**：直接走强但没给回踩机会，注意不追高；
   - **未回踩走弱**：观察降级；
4. 每条记录带修正建议，供次日选股时参考（失效的股票不再沿用）。

核对结果按天存在 `daily_picker/cache/verify/` 下，重启服务不丢。

> 注意：网页版和命令行共用 `daily_picker/cache/`，跑过一次后，换日期或调参都能秒出结果。服务需保持运行，关掉终端即停止。

## 快速开始

```bash
# 最近交易日数据，输出 md + docx
python pick_stocks.py

# 指定数据日期（盘后复核用）
python pick_stocks.py --date 2026-08-14

# 只看 Markdown，输出到 reports 目录
python pick_stocks.py --top 10 --format md --out-dir ./reports

# 离线模式：用本地缓存重新出报告
python pick_stocks.py --offline

# 直连失败时，可手动指定本地代理（Clash 等）
python pick_stocks.py --proxy socks5h://127.0.0.1:7897
```

运行后在当前目录（或 `--out-dir`）生成：

- `A股短线候选_YYYY-MM-DD.md`
- `A股短线候选_YYYY-MM-DD.docx`（安装了 python-docx 时）

## 选股口径

规则完全对齐工作区历史日报《A股短线候选_2026-07-07》：

1. 非 ST，剔除新股/退市风险标的（上市不足 60 个交易日）。
2. 今日收红（若指数下跌即为“逆势收红”，报告里会注明市场环境）。
3. 成交额 ≥ 5 亿元，换手率 ≥ 3%。
4. 收盘站上 20 日线，优先 5 日线 > 10 日线。
5. MACD 黄白线在 0 轴上方，或 MACD 金叉/柱体改善。
6. KDJ 金叉或低中位拐头，但不过热（J ≤ 95）。
7. 近 5 日涨幅 ≤ 25%、10 日涨幅 ≤ 40%，涨停或接近涨停的只列为“等回踩”。

输出分三类：**优先观察**（综合评分 Top N）、**强势但不宜追高**（接近涨停 / 涨幅透支 / KDJ 过热）、**剔除或降级观察**（未通过硬性规则但有代表性的样本）。

## 数据源与缓存

- 主数据源：东方财富公开接口（全市场快照 + 日K前复权）。
- 兜底数据源：新浪财经（全市场列表 + 日K，东财不可达时自动切换）。
- 所有原始数据缓存在 `daily_picker/cache/<日期>/` 下，可离线重出报告。

网络通道会按顺序自动探测：`urllib(系统代理)` → `curl(直连)` → `curl(系统HTTP代理)` → `curl(系统SOCKS代理)`，首次探测成功后整轮复用，避免重复重试。部分代理对 Python 的 TLS 指纹不友好（东财接口偶发“RemoteDisconnected”），此时工具会自动切到 curl 通道；如果自动探测全部失败，用 `--proxy` 手动指定代理即可。

> 注意：接口为公开免登录服务，仅用于个人研究，请遵守数据源使用条款。收盘前（当日 15:05 之前）运行默认为“盘中预览”，不列正式候选；确认要盘中看预览可加 `--allow-intraday`。

## 每日自动运行 + 邮件推送

工作区已配置 Codex 每日自动化（每交易日 18:00，Asia/Shanghai），任务会：

1. 运行 `python daily_update.py --date 今日`（直连不稳加 `--proxy socks5h://127.0.0.1:7897`）：完成当日选股、生成 md/docx 与网页数据，并增量更新历史回放和预判核对；
2. 运行 `scripts/send_report_email.py` 把报告发送到配置的收件邮箱；
3. 邮件发送失败时会在自动化报送中明确说明原因，不会静默跳过。

也可以手动执行盘后更新：

```bash
python daily_update.py                    # 最近交易日
python daily_update.py --date 2026-08-14  # 指定日期
python daily_update.py --offline          # 断网时用缓存
python daily_update.py --send-email --to 365941027@qq.com
```

## 微信小程序

工作区还带一个微信小程序客户端（[wechat_miniprogram/](wechat_miniprogram/README.md)），页面结构与网页版一致（选股 / 预判核对 / 自选 / 持仓 / 板块热度 / 个股K线+缠论标注 / 订阅推送入口），对接同一个本地后端。微信开发者工具已安装在本机，首次使用需微信扫码登录后导入 `wechat_miniprogram` 目录即可开发调试；正式上线需要 HTTPS + ICP 备案域名。

首次使用前需要配置 QQ 邮箱 SMTP 授权码（一次性）：

```bash
# 在 QQ 邮箱网页版：设置 -> 账号 -> 开启 SMTP 服务，拿到 16 位授权码
security add-generic-password -U -a 你的QQ邮箱 -s "A股选股报告推送" -w "你的16位授权码"
```

也可以用环境变量临时指定：

```bash
SMTP_USER=你的QQ邮箱 SMTP_AUTH_CODE=16位授权码 \
  python scripts/send_report_email.py --date 2026-08-14 --to 365941027@qq.com
```

手动测试发送（先手动跑一次确认能收到）：

```bash
python scripts/send_report_email.py --date 2026-08-14 --to 365941027@qq.com
```

## 全部参数

| 参数 | 说明 |
| --- | --- |
| `--date YYYY-MM-DD` | 行情数据日期，默认最近交易日 |
| `--observe-date YYYY-MM-DD` | 报告里的“观察日”，默认数据日后的下一交易日 |
| `--top N` | 优先观察数量，默认 8 |
| `--format md/docx/both` | 输出格式，默认 both |
| `--out-dir DIR` | 输出目录，默认当前目录 |
| `--offline` | 仅用本地缓存，不联网 |
| `--refresh` | 忽略缓存重新拉取 |
| `--allow-intraday` | 盘中数据也输出正式候选 |
| `--max-workers N` | 日K拉取并发数，默认 10 |
| `--proxy URL` | 手动指定代理，如 `http://127.0.0.1:7897`、`socks5h://127.0.0.1:7897` |
| `--verbose` | 打印详细进度 |

## 内部结构

```text
daily_picker/
├── config.py       # 全部筛选阈值（可改）
├── data_fetch.py   # 行情抓取 + 缓存 + 兜底源
├── indicators.py   # MA / MACD / KDJ / 涨幅（纯标准库）
├── screening.py    # 过滤、评分、归类
├── report.py       # Markdown / Word 渲染
├── cli.py          # 命令行入口
└── cache/          # 本地数据缓存
```

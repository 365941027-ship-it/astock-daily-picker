# A股每日选股 · 微信小程序

基于工作区现有选股后端（`webapp.py`）的微信小程序客户端，包含三个页面：

- **选股**：选日期、优先数量、代理 → 运行 → 市场概况 + 优先观察/强势不宜追高/剔除表格
- **核对**：选核对日 → 查看前一交易日候选的实际表现（兑现/失效/修正建议）
- **自选**：添加/删除自选股，设“跌破/突破”价格提醒，刷新时自动比对
- **持仓**：模拟账户总览（总资产/盈亏/可用资金）+ 记交易（买入/卖出）+ 持仓盈亏 + 交易记录
- **个股详情**：日K/60分/30分周期切换，K 线（MA5/10/20）+ MACD/KDJ 指标 + 缠论中枢标注 + 分享卡片
- **板块热度**：行业板块涨跌榜（东财主源 + 新浪兜底），辅助判断板块同步

## 在微信开发者工具中打开

1. 已安装微信开发者工具（本机已装到 `/Applications/wechatwebdevtools.app`）。
2. 打开工具，用微信扫码登录（首次运行必须登录）。
3. 「导入项目」→ 目录选择本文件夹：`/Users/yexiyan/Documents/A股复盘/wechat_miniprogram`
4. AppID 选择「测试号」（本项目已配置 `touristappid`，无需注册）。
5. 确认「详情 → 本地设置 → 不校验合法域名」已勾选（`project.config.json` 已默认 `urlCheck: false`）。
6. 先启动后端：`python webapp.py`（默认 http://127.0.0.1:8235），再点「编译」。

## 数据来源

小程序本身不做计算，所有数据来自本地后端：

- `POST /api/run` 启动选股，`GET /api/status` 轮询进度
- `GET /api/kline?code=&date=` 个股K线
- `GET /api/kline?code=&date=&klt=60|30` 分钟K线（含缠论中枢标注）
- `GET /api/verify?date=` 预判核对
- `GET/POST /api/watchlist`、`POST /api/trade`、`GET /api/userdata` 自选/持仓/交易
- `GET /api/sectors` 板块热度

后端地址在 `app.js` 的 `globalData.baseUrl`（当前 `http://127.0.0.1:8235`）。

## 真机预览 / 上线注意

- 开发阶段：DevTools 勾选“不校验合法域名”即可用 `127.0.0.1`；真机调试时，手机需和电脑同一局域网，并把 `baseUrl` 改为电脑的局域网 IP（如 `http://192.168.x.x:8235`），同时后端用 `--host 0.0.0.0` 启动。
- 正式上线：微信要求请求域名必须是 **HTTPS 且已 ICP 备案** 的域名（即上一轮部署方案 A 的云服务器 + 域名），把 `baseUrl` 改为 `https://你的域名`，并在小程序后台「服务器域名」里配置 request 合法域名。未备案前无法对大众发布。
- 小程序主体需为个人或企业主体（个人主体可发布非金融交易类工具，但涉及“选股”类目时可能被要求金融资质，正式提审前请确认类目要求）。
- 订阅消息推送：代码入口已预留（选股页“订阅每日推送”），正式发布需真实订阅消息模板 ID 与 access_token；测试号无法真实发送。
